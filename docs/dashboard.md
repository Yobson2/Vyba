# Admin dashboard — `Vyba-dashboard-admin/`

React admin dashboard for platform operators. Bootstrapped from a React admin
template — see [`Vyba-dashboard-admin/README.md`](../Vyba-dashboard-admin/README.md)
for the template overview and stack versions.

**Stack**: React 19 + TypeScript (strict) + Vite + TailwindCSS v4 + shadcn/ui
(Radix). Package manager: **pnpm**.

## Commands

```bash
pnpm install
pnpm dev            # Vite dev server
pnpm build          # tsc type-check + Vite build
pnpm lint           # ESLint
pnpm format         # Prettier
pnpm format:check
pnpm knip           # unused deps / exports
```

## Environment

Vite vars prefixed `VITE_`: `VITE_API_URL` (default `/api`),
`VITE_AUTH_TOKEN_KEY` (cookie key, default `app_access_token`), `VITE_APP_NAME`.
`VITE_`-prefixed values are embedded in the client bundle — public config only.

## Architecture — feature-based

Features under `src/features/<name>/` (auth, dashboard, users, venues, bookings,
promotions, reviews, tasks, settings, analytics, errors, landing-page).

`@/` maps to `./src/` (configured in `vite.config.ts` + tsconfig).

### The CRUD-resource pattern

Most features are one resource rendered as a data table with dialog-driven
create/edit/delete. Each such feature has:

```
data/schema.ts        # zod schema + <item>ListSchema + inferred TS types
data/<name>.ts         # mock data (parsed through the schema in index.tsx)
data/data.ts           # badge class maps, role/status option lists
context/<name>-context.tsx   # useDialogState + currentRow, use<Name>() hook
components/<name>-columns.tsx / <name>-table.tsx / <name>-dialogs.tsx
components/<name>-action-dialog.tsx / <name>-delete-dialog.tsx / <name>-primary-buttons.tsx
components/data-table-*.tsx   # column-header, faceted-filter, pagination, row-actions, toolbar, view-options
index.tsx              # Header/Search/ThemeSwitch + Main + Provider shell
```

The six `data-table-*.tsx` files are currently duplicated verbatim across every
feature. Shared versions live in `src/components/ui/data-table/` — prefer
importing from there and lift missing pieces up rather than pasting another copy.

To scaffold a new resource feature, use the **`dashboard-crud-feature`** skill.

## Routing (TanStack Router)

File-based in `src/routes/`; the route tree (`routeTree.gen.ts`) is
auto-generated by the Vite plugin — don't edit it by hand.

- `(auth)/` — public auth routes (sign-in, sign-up, forgot-password, otp)
- `_public/` — landing page
- `_authenticated/` — protected routes with sidebar layout. `route.tsx` carries a
  `beforeLoad` guard (`isTokenExpired` → `redirect('/sign-in')`).
- `(errors)/` — 401 / 403 / 404 / 500 / 503

Nav entries: `src/components/layout/data/sidebar-data.ts`.

## State management

- **Zustand** (`src/stores/authStore.ts`) — auth user + access token, token
  persisted in cookies via `js-cookie` with `{ secure, sameSite: 'strict', expires: 7 }`.
- **TanStack Query** — server state; 0 retries in dev / 3 in prod, no retry on
  401/403, 10s stale time.
- **React Context** — theme (light/dark/system + localStorage), font selection,
  command palette (Ctrl+K).
- **Feature contexts** — per-feature dialog/form state (`use<Name>()` returning
  `{ open, setOpen, currentRow, setCurrentRow }`).

## API layer

- Axios instance in `src/api/axios-instance.ts` — request interceptor attaches
  the Bearer token, response interceptor logs out on 401.
- Endpoint constants in `src/api/endpoints.ts`.
- Typed responses: `ApiResponse<T>`, `PaginatedResponse<T>`, `ApiError`
  (`src/api/types.ts`).
- `handleServerError()` extracts Axios error messages and toasts via Sonner.

## UI patterns

- shadcn/ui primitives in `src/components/ui/`.
- Data tables: TanStack Table (sorting, filtering, faceted filters, pagination,
  row selection).
- Forms: React Hook Form + Zod (`zodResolver`).
- Animations: Framer Motion wrappers in `src/components/motion/`.
- Layout: collapsible `app-sidebar.tsx`, fixed header with scroll shadow,
  responsive `Main` wrapper.
- `cn()` (`src/lib/utils.ts`) = clsx + tailwind-merge.
- Design tokens: `src/index.css` (Tailwind v4 `@theme`). See
  [`design-system.md`](design-system.md).

## Lint & format

ESLint: no `console.log`, react-hooks, react-refresh, TanStack Query plugin,
unused vars (ignores `_` prefix). Prettier: single quotes, trailing commas, 80
cols, import sorting, Tailwind class sorting. Never add `eslint-disable` for
`no-console` or other security-relevant rules.
