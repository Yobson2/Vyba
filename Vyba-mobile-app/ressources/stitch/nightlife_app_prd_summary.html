# Nightlife Discovery & Booking App — Product Requirements Document ## 1. Context A mobile-first nightlife discovery and booking platform for West Africa (e.g., Abidjan, Cocody). - **Clients:** Discover bars/maquis, book tables, view promos. - **Venue Owners:** Manage profiles, promos, and bookings. ## 2. Design System Core - **Colors:** Primary #6366F1 (Indigo), Secondary #10B981 (Emerald), Accent #F59E0B (Amber), Background #F8FAFC (Light) / #0F172A (Dark). - **Typography:** Inter (Google Fonts). Headlines 24-28px, Body 14-16px. - **Radius:** 12px for cards/buttons, 8px for inputs. - **Style:** Modern, vibrant, photography-forward. Dark mode feels premium. ## 3. Key Features - **Explore:** Map/List toggle, filter chips (Open Now, Promo Active). - **Booking:** 3-step flow (Date/Time, Party Size, Confirm). - **Feed:** Promotions and events scroll. - **Owner Dashboard:** Quick stats and booking management. ## 4. User Flows - **Client:** Onboarding -> Explore -> Venue Detail -> Book -> Confirmation. - **Owner:** Dashboard -> Booking Management -> Promo Creation.
